# What's new in Testnexa

Stay up to date with the latest features, architectural enhancements, and documentation releases across the Testnexa platform.

> Note: Testnexa releases continuous updates to enhance suite generation accuracy, pipeline connectivity, and coverage traceability.

## Release notes

### November 2026: Help Center Overhaul & CI/CD Integrations
- **Complete Help Center Overhaul**: Redesigned documentation architecture featuring structured markdown content, build-time typed search indexing, instantaneous keyboard navigation (`/` or `Ctrl+K`), and strict monochrome styling.
- **Support & Status Infrastructure**: Integrated Contact Support modal with honeypot spam protection, real-time ticket dispatch, and live system status tracking via `/api/v1/status`.
- **CI/CD Integrations Phase 1**: Added GitHub App authorization, repository linking, and Playwright workflow export under **Integrations > CI/CD**.
- **Strict Black-and-White Theme**: Full UI alignment across all pages with zero color representing meaning alone, meeting WCAG AA contrast standards.

### October 2026: Risk Matrix & Coverage Engine
- **5×5 Risk Matrix**: Visualized Likelihood and Impact breakdown with one-click filtering.
- **Dual-Metric Traceability**: Established strict separation between Linked Coverage (design-time requirement mapping) and Verified Coverage (execution-time CI passes).
- **Batch Test Approvals**: Introduced bulk review and approval workflows for newly generated test cases.

Clear visibility into the latest platform capabilities and continuous engineering improvements.
